# ai-broker
A web platform for managing broker missions, will be utilizing AI agents to match consultants with the right opportunities in real-time.

# Phases
## Phase 1: MVP or proof of concept
- Basic database structure
- Endpoints
- Simple webpage

## Phase 2
- Use AI agents

## Phase 3
- Scrap webpages

## Phase 4
- Security
- Deploy (?)


# Phase1: 
- Basic database structure
    - Candidates
        - Personal Data
        - Available
        - Abilities

    - Broker
        - Name
        - Webpage
        - Missions
            - Description
            - Abilities

- Endpoints
    - CRUD: CV, Brokes, Missions
    - Find matches

- Simple webpage
